# booga.me → booga.civ.fm

This repo exists only to hold the `booga.me` domain and forward it to
[booga.civ.fm](https://booga.civ.fm/), which is served from `boogaav/booga-retro-site`.

`404.html` is a copy of `index.html` so that any path, not just the root, forwards too.
Don't delete the `CNAME` file — GitHub detaches the domain on the next push if it goes.
